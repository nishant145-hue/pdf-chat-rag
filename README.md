# PDF Chat RAG Application

A production-style Retrieval-Augmented Generation (RAG) application built using FastAPI, FAISS, Sentence Transformers, and Groq.

## Features

- PDF Upload
- Text Extraction
- Recursive Chunking
- SentenceTransformer Embeddings
- FAISS Vector Search
- Cross-Encoder Reranking
- Groq LLM
- Multi-document Support
- Persistent Vector Store
- Structured Logging
- Configurable Settings

## Tech Stack

- Python
- FastAPI
- FAISS
- Sentence Transformers
- Groq API
- Pydantic
- NumPy
